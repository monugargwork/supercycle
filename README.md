# Story reels

Animated story reels (1080x1920, 30 fps, rendered at 1440x2560) made with three.js inside Remotion: flat cartoon characters in an inked 3D world, real TCG cards, Vietnamese voiceover.

Start with [`CLAUDE.md`](CLAUDE.md).

Built on the free *cartoon-3d-short* skill from mromidev/claude-animated-shorts. Its original kit is kept in `SKILL.md`, `templates/` and `references/`, and its README is in `docs/history/original-skill-README.md`.
